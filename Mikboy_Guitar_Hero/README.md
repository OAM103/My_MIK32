# Guitar Hero Mini Edition for MikBoy (MIK32 Амур)

Проект представляет собой портативную ритм-игру в стиле Guitar Hero, разработанную для игровой консоли MikBoy на базе микроконтроллера MIK32 Амур. Игрок должен нажимать кнопки направления в такт музыке, когда летящие стрелки достигают зоны попадания.

Игра сочетает в себе:

- синхронизацию музыки и игровых событий;
- отрисовку графики на дисплее ST7735;
- воспроизведение аудио через DAC;
- систему подсчёта очков и оценок;
- экран обратного отсчёта перед началом игры;
- итоговую статистику прохождения.

# Особенности проекта

## Ритм-геймплей

Игровая механика построена вокруг заранее подготовленной нотной карты.

Каждая нота содержит:

- время появления;
- дорожку движения.

Пример записи ноты:

cpp
{41 * SEC + 510, 0},
{42 * SEC + 184, 2},
{42 * SEC + 445, 3},
Где:

* первое значение — время появления в миллисекундах (SEC = 1000 мс);
* второе значение — дорожка:

| Значение | Направление |
| -------- | ----------- |
| 0        | Вверх       |
| 1        | Вниз        |
| 2        | Влево       |
| 3        | Вправо      |

---

## Система состояний игры

Вся игра построена на конечном автомате.

cpp
enum class GameState
{
    START,
    COUNTDOWN,
    RUNNING,
    GAME_OVER
};

### START

Отображается заставка.

Ожидается нажатие кнопки A.

### COUNTDOWN

Показывается обратный отсчёт:

* READY?
* 3
* 2
* 1

### RUNNING

Основной игровой цикл:

* генерация стрелок;
* обработка ввода;
* обновление позиции объектов;
* воспроизведение музыки.

### GAME_OVER

Отображается итоговый результат прохождения.

# Архитектура проекта

## Main.cpp

Главный цикл приложения.

Отвечает за:

* инициализацию оборудования;
* запуск аудиосистемы;
* переключение состояний игры;
* обработку двойной буферизации звука.

Фрагмент главного цикла:

cpp
while (1)
{
    switch (game_state)
    {
        case GameState::START:
            ...
            break;

        case GameState::COUNTDOWN:
            ...
            break;

        case GameState::RUNNING:
            arrow_animation(mik);
            break;

        case GameState::GAME_OVER:
            ...
            break;
    }
}

## Game.cpp

Содержит игровую логику.

Основные функции:

### Создание стрелок

cpp
void spawn_arrow_lane(int lane)
{
    arrows[i].active = true;
    arrows[i].y = 20;
    arrows[i].lane = lane;
}

### Движение стрелок

cpp
arrows[i].y += ARROW_SPEED * delta_time;

Скорость зависит от реального времени, а не от количества кадров.

---

### Проверка попадания

cpp
bool is_hit(uint16_t y)
{
    return (y >= HIT - HIT_WINDOW &&
            y <= HIT + HIT_WINDOW);
}

Игрок получает очки только при попадании в область HIT.

---

## Music.cpp

Отвечает за:

* воспроизведение музыкального трека;
* микширование звука;
* заполнение DAC-буферов;
* воспроизведение звуков ошибок.

Используется двойная буферизация:

cpp
uint16_t dac_buf0[DAC_BUF_SIZE];
uint16_t dac_buf1[DAC_BUF_SIZE];
`

Пока один буфер воспроизводится, второй заполняется новыми данными.

# Система подсчёта очков

## Попадание

За успешное попадание:

hits += 10;
---

## Неверное нажатие

За ошибку:

hits -= 5;
Также проигрывается звук ошибки.

---

## Пропущенная стрелка

Если стрелка покинула экран:

hits -= 3;
---

# Система рангов

После завершения песни игрок получает ранг.

Примеры:

| Ранг | Описание          |
| ---- | ----------------- |
| F    | you loser         |
| D    | nice try          |
| C    | nice job          |
| B    | skilled           |
| A    | rock hero         |
| S    | you are rock star |

Оценка вычисляется относительно максимального возможного количества очков.

float percent = (float)score / MAX_SCORE;
return (uint8_t)(percent * (GRADE_COUNT - 1));

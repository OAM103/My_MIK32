# MIK32 LCD + Touchpad

Прошивка для **MIK32 Амур**: LCD дисплей (480×320) и тачпад. При касании экрана рисуется красная линия.

## Описание

После включения экран очищается белым цветом. В основном цикле считываются координаты тачпада, преобразуются в пиксели дисплея и рисуется штрих между последовательными точками касания.

Основные возможности:

- инициализация SPI-дисплея и тачпада;
- DMA-заливка экрана;
- фильтрация шума и защита от «скачков» при отрыве пальца.

## Калибровка тачпада

Параметры задаются в `lib/touchpad/touchpad.h`:

| Макрос | Назначение |
|--------|------------|
| `TOUCH_MIN_RAW_X` | Минимум сырой координаты X |
| `TOUCH_MIN_RAW_Y` | Минимум сырой координаты Y |
| `TOUCH_MAX_RAW` | Максимум сырых координат |
| `TOUCH_SCREEN_W` | Ширина области касания (480) |
| `TOUCH_SCREEN_H` | Высота области касания (320) |

Если метка смещена относительно пальца — подберите `TOUCH_MIN_RAW_*` и `TOUCH_MAX_RAW` по фактическим значениям с тачпада.

## Настройка отрисовки

В `lib/touchpad/touchpad.h`:

| Макрос | По умолчанию | Описание |
|--------|--------------|----------|
| `TOUCH_DOT_SIZE` | 3 | Толщина штриха (пиксели) |
| `TOUCH_DRAW_COLOR` | `0xF800` | Цвет линии (красный, RGB565) |
| `TOUCH_FILTER_SAMPLES` | 8 | Число замеров для усреднения |
| `TOUCH_MAX_JUMP` | 60 | Порог скачка координат (пиксели) |

Режимы рисования в `touchpad.c`:

- `touch_draw_lines()` — непрерывный штрих (используется в `main.c`);
- `process_touchpad()` — маркер 10×10 в точке касания.
